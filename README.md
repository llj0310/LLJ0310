# Your Card Site

## 本站说明

这是一个基于**本地存储**的字卡传讯网站原型。所有数据都保存在您的浏览器中，**不会上传至任何服务器**。

## 核心功能

### 1. 数据持久化
- 页面刷新或关闭，**数据不会丢失**
- 所有计数、设置都自动保存在浏览器本地

### 2. 备份与恢复
- **导出**：点击右上角 "💾 导出" 按钮，下载一个 JSON 备份文件
- **导入**：点击 "📥 导入"，选择之前下载的备份文件，可恢复数据
- **重要**：建议定期导出备份，特别是在更换设备或清理浏览器数据前

### 3. 今日统计
- **摸鱼值**：记录今天的摸鱼次数
- **工作值**：记录今天的工作次数
- 点击对应按钮即可计数

## 浏览器注意事项

- 数据保存在**当前浏览器**的 LocalStorage 中
- 不同浏览器（Chrome/Edge/Safari）数据不互通
- iOS Safari 每 7 天可能会自动清空本地数据
- **强烈建议**：定期使用 "导出功能" 备份重要数据

## 快速开始

1. 双击打开 `index.html` 文件，即可在浏览器中运行
2. 点击 "+ 摸鱼" 和 "+ 工作" 按钮进行计数
3. 刷新页面验证数据是否保留
4. 点击 "💾 导出" 下载备份，点击 "📥 导入" 恢复数据
